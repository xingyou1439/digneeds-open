# Roadmap

The next milestone is repeatable use by independent researchers. Stars are a discovery signal, not proof of demand.

- [x] Offline JSON CLI with no API key or runtime dependency.
- [x] Explicit synthetic-fixture labeling and reproducible output.
- [ ] Counterexample suite for negation, sarcasm, ambiguous products and promotional questions.
- [ ] English display labels without changing stable signal IDs.
- [ ] Three independently reproduced research workflows, with permission to publish the results.
- [ ] A small human-labeled evaluation set; report precision/recall by signal only after labels and denominators are reviewed.

Good first contributions: a failing test for a negated complaint; an English translation of the methodology; documentation of a field alias from a permission-cleared input. Discuss the expected behavior before changing a rule. See [CONTRIBUTING](CONTRIBUTING.md).

No scraping infrastructure, accounts, payment code, market-size estimates or automatic Reddit posting are planned for this repository.
