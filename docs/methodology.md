# 研究方法

DigNeeds 的公开规则把 Reddit 公开讨论当作“可追溯的研究线索”，而不是代表性市场样本或销售预测。

## 流程

1. **收集**：从上游搜索结果递归读取帖子对象，只接受 `reddit.com`、`www.reddit.com`、`old.reddit.com` 的真实 `/comments/<id>/` 路径。
2. **清洗**：按 Reddit 帖子 ID 去重；同一个 ID 保留正文更长的版本；去除推广标记、NSFW 标记和无效链接；正文最多保留 3000 字符。
3. **相关性**：把查询转为去重后的英文词元，去掉常见停用词并做有限的复数归一化。所有词必须在同一短句的近邻窗口内出现，链接文本不参与匹配。
4. **信号**：在标题和正文中寻找使用痛点、求推荐、寻找替代、购买意向四类表达，并为每个标签保存触发它的原文片段。
5. **主题**：将有信号的帖子归入耐用与可靠性、清洁与维护、空间与便携、价格与价值、使用体验五类主题；一个帖子可以属于多个主题。
6. **排序**：按查询词数量、信号数和带信号评论数计算阅读优先级，然后按时间作为次级排序。这个分数只安排阅读顺序。
7. **复核**：打开原帖、记录反例、核查替代品和成本，再进行样品、价格或用户验证。

## 证据边界

- 价格、折扣、求推荐本身不等于购买意向；只有预算、准备购买、愿意付费或询问购买渠道等表达才触发购买线索。
- 促销社区、促销文案和没有正文/评论的商品上架帖会被剔除，除非帖子本身有需求信号。
- 主题数量不是独立用户数，社区数不是市场规模，排序分不是成功概率。
- 规则可能漏判或误判；原帖删除或编辑后，历史快照可能与当前内容不同。
- 代码只做规则初筛，不调用额外大模型，也不伪造空结果。

## 适用范围

该模块适用于英文产品关键词和 Reddit 帖子/评论数据。它不负责抓取、鉴权、账户、额度、支付、数据库、网页渲染或部署；这些属于原始线上应用的私有实现。
